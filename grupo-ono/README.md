# Grupo ONO · corporate site

Static site for Grupo ONO (ONO Hosomaki Bar in Bogotá and Casa Salvaje in Cartagena). It lives in this folder, separate from the Casa Salvaje site. English only, except on `careers.html`: one line inviting applicants to write in Spanish, and the consent sentence in both languages (marked `lang="es"`). The AXXIS article title in the contact page's press list keeps its original Spanish (also marked `lang="es"`).

Source: the pages are generated, so never edit `grupo-ono/*.html` by hand. Edit the templates in `grupo-ono-src/tpl/` (and `grupo-ono-src/logo_*.svg` for the logo), then run `python3 grupo-ono-src/build.py` from the repo root. `grupo.css` and `grupo.js` here are edited directly. The icon and share-card generator and the outlined-GRUPO script are in `grupo-ono-src/tools/`. The source folder sits outside the Netlify base directory, so it is never published (and `_redirects` at the repo root keeps it off casa-salvaje.com).

Pages: `index.html` (hero with the self-drawing logo, manifesto with the openings timeline, one chapter per brand, links to careers and contact), `careers.html`, `contact.html` (with the press block at `contact.html#press`), `privacy.html`, `thanks.html`. The logo is redrawn as a vector in `img/logo-grupo-ono.svg` and inlined in every page.

Press kit: `press/grupo-ono-press-kit.zip` (logos, ONO and Casa Salvaje images, the fact sheet and a README listing every file) and `press/grupo-ono-fact-sheet.pdf` (one A4 page), both linked from `contact.html#press`. They are generated by `grupo-ono-src/press_kit.py`: rebuild the kit first, then the pages, because the build writes the ZIP's size into the contact page.

On Netlify: new site from this same repo, **Base directory = `grupo-ono`**, no build command, publish = `.` (set in `netlify.toml`). The `careers` (with a PDF CV) and `contact` forms go to Netlify Forms; turn on email notifications under Site settings → Forms.

Live domain: `https://grupo-ono.com`. Canonical links, `og:url` and `og:image` are absolute on that origin (`SITE` in `grupo-ono-src/build.py`), so share previews only work once the domain serves the site.
